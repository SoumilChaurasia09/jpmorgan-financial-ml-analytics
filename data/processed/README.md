# Processed & Star Schema Datasets

This directory contains the cleaned, validated, and normalized data tables generated by `python/data_cleaning.py`.

## Table Inventory

| File Name | Schema Role | Record Count | Description |
| :--- | :--- | :--- | :--- |
| `financial_sales_cleaned.csv` | Denormalized Table | 700 rows | Fully cleaned flat transaction table with standardized headers, imputed discount bands, derived profit margins, and primary key `transaction_id`. |
| `dim_product.csv` | Dimension Table | 6 rows | Product dimension containing `product_id` (PRD001-PRD006), `product_name`, and `standard_manufacturing_price`. |
| `dim_country.csv` | Dimension Table | 5 rows | Country dimension containing `country_id` (CTR01-CTR05), `country_name`, and continental `region`. |
| `dim_segment.csv` | Dimension Table | 5 rows | Customer segment dimension containing `segment_id` (SEG01-SEG05), `segment_name`, and `channel_type` (B2B, B2G, B2B/B2C). |
| `dim_date.csv` | Conformed Dimension | 730 rows | Full calendar table covering 2013-01-01 to 2014-12-31 with `date_key`, `year`, `quarter`, `quarter_name`, `month_number`, `month_name`, `is_weekend`. |
| `fact_financials.csv` | Core Fact Table | 700 rows | Transaction fact table linking to dimensions via foreign keys with units, revenue, COGS, discounts, and gross margins. |
| `simulated_budget.csv` | Illustrative Fact Table | 400 rows | Separate monthly budget targets by Country and Segment for 2013-2014. Target revenue pegged at +5% over benchmark with 18% target gross margin. |
| `simulated_operating_expenses.csv` | Illustrative Cost Fact | 80 rows | Departmental operating expense allocations (SG&A, R&D, Marketing, IT) by month and segment. |

> **Architectural Separation Note:** Actual operational results (`fact_financials.csv`) are strictly segregated from simulated budget targets (`simulated_budget.csv`) and departmental expenses (`simulated_operating_expenses.csv`) to uphold reporting transparency and auditability.
